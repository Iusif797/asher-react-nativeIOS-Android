# ASHER

Персональная система психологического благополучия. Не «календарь с кнопкой записаться», а ежедневный инструмент: психолог — часть приложения, а не наоборот.

## Запуск

```bash
npm install
npm run dev
```

Продакшен-сборка: `npm run build`, предпросмотр: `npm run preview`.

## Что внутри

Все пять уровней продуктовой концепции:

1. **MVP** — личный кабинет (история и предстоящие консультации, онлайн-оплата, документы и чеки, чат с администратором), прозрачная запись (время, формат, стоимость, опыт, направления, языки, отзывы), умный подбор психолога за 10 вопросов с объяснением «почему именно они».
2. **Ежедневная польза** — дневник настроения с графиком, дневник мыслей, домашние задания от психолога, библиотека знаний по жизненным ситуациям.
3. **AI-помощник** — помогает сформулировать запрос, сориентироваться в выборе специалиста и разобраться с заданиями. Не ставит диагнозов и не заменяет психолога.
4. **Удержание** — программа «30 дней снижения тревожности», группы, курсы, подписка ASHER+.
5. **B2B** — корпоративная программа с агрегированной статистикой без раскрытия содержания обращений.

Флагманская функция — **персональная дорожная карта изменений**: не диагноз, а индивидуальный план с этапами, навыками и понятным ощущением движения вперёд.

Отдельный режим — **кабинет специалиста**: расписание, карточки клиентов, заметки, назначение заданий по шаблонам.

## Стек

- React 18 + TypeScript (strict) + Vite
- React Router, Zustand (persist в localStorage)
- Чистый CSS: дизайн-токены в `src/styles/tokens.css`, типографика Cormorant Garamond + Manrope

## Структура

```
src/
├── app/          каркас: роутинг, сайдбар, мобильная навигация
├── components/ui UI-кит: Button, Modal, Tag, Progress, Icon и др.
├── features/     экраны по фичам: today, roadmap, booking, matching,
│                 diary, homework, library, programs, assistant,
│                 account, therapist, b2b
├── data/         контент: направления, специалисты, программы, библиотека
├── stores/       zustand-сторы: настроение, мысли, задания, записи
├── lib/          типы, даты, форматирование
└── styles/       токены и глобальные стили
```

Данные демонстрационные и хранятся локально; бэкенд подключается заменой слоя `data/` и `stores/`.
