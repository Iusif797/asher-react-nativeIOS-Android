# Бэкенд ASHER

## Архитектура

**Supabase** (управляемый Postgres) — оптимальный выбор для этого класса приложений: банк-уровень приватности через Row Level Security на уровне БД, готовая аутентификация, realtime для чатов, storage для документов и edge-функции для AI — без содержания собственных серверов.

```
iOS / Android (Capacitor)
        │ HTTPS + JWT
        ▼
┌─ Supabase ────────────────────────────────┐
│ Auth        Sign in with Apple / Google,  │
│             email OTP                     │
│ Postgres    схема + RLS-политики          │
│ Realtime    чат с администратором         │
│ Storage     документы, чеки, аудио/видео  │
│ Edge Fns    AI-помощник (прокси Claude),  │
│             платёжные вебхуки             │
└───────────────────────────────────────────┘
        │ server-side ключи
        ▼
  Claude API · платёжный провайдер · APNs/FCM
```

## Модель приватности (главное в психологическом сервисе)

Политики в `supabase/migrations/0002_rls.sql` гарантируют на уровне БД:

- **Клиент** видит и меняет только свои данные (дневники, встречи, задания, чат).
- **Психолог** видит клиентов только с реальными консультациями у него; дневник мыслей — только записи, отмеченные «обсудить с психологом».
- **Работодатель (B2B)** не имеет доступа ни к одной строке данных сотрудников. Единственный вход — функция `company_stats()`: агрегированные счётчики, с проверкой, что вызывающий — админ именно этой компании.
- **AI-ключи** живут только в edge-функциях, в приложение не попадают.

## Подключение (по шагам)

1. Создать проект на [supabase.com](https://supabase.com) (бесплатный тариф достаточен для старта).
2. `npx supabase login && npx supabase link --project-ref <ref>`
3. `npx supabase db push` — применит обе миграции.
4. Скопировать `.env.example` → `.env`, вписать `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` (anon-ключ безопасен для клиента — доступ ограничивает RLS).
5. `npm i @supabase/supabase-js`, создать `src/lib/supabase.ts` c клиентом.
6. Перевести сторы с seed-данных на запросы: точка замены — `src/stores/*` (данные входят в приложение только там; UI менять не нужно).
7. Залить контент (направления, программы, библиотека, специалисты) из `src/data/*` — структура таблиц один-в-один повторяет типы приложения.

## AI-помощник (уровень 3 концепции)

Edge-функция `assistant`: принимает сообщение → системный промпт («помощник ASHER, не психолог, не ставит диагнозов, помогает сформулировать запрос и навигирует») → Claude API (модель `claude-sonnet-5`) → ответ. Ключ Anthropic — в секретах Supabase. Клиент дергает функцию через `supabase.functions.invoke('assistant')` с JWT — анонимного доступа нет.

## Платежи

Для Азербайджана: локальный эквайринг (Kapital Bank / PashaPay / Payriff) через edge-функцию создания заказа + вебхук, который помечает `payments.status = 'paid'` и `consultations.paid`. Подписки и курсы при продаже цифрового контента в приложении Apple потребует проводить через In-App Purchase (StoreKit) — это правило App Store; консультации живого специалиста можно продавать внешним эквайрингом.
